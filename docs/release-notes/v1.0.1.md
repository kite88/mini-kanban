## v1.0.1 · 标题与品牌统一

小修订版：功能、接口、数据库结构都没有变化，只是把产品名与浏览器标签页标题统一了。

### 这次改了什么

- **产品名统一为 `Mini-Kanban`**：导航栏品牌、标签页标题、登录页标题都取同一个名字，中英文一致
  （原来是「任务看板」/ `Task Board`）。
- **标签页标题改成「页面名 - Mini-Kanban」**，逐页区分：

  | 页面 | 中文界面 | 英文界面 |
  | --- | --- | --- |
  | `/login` | `登录 - Mini-Kanban` | `Sign in - Mini-Kanban` |
  | `/projects` | `项目 - Mini-Kanban` | `Projects - Mini-Kanban` |
  | `/projects/<id>` | `任务看板 - Mini-Kanban` | `Task board - Mini-Kanban` |
  | `/users` | `用户管理 - Mini-Kanban` | `Users - Mini-Kanban` |
  | `/departments` | `部门管理 - Mini-Kanban` | `Departments - Mini-Kanban` |
  | `/logs` | `操作日志 - Mini-Kanban` | `Activity logs - Mini-Kanban` |
  | `/trash` | `回收箱 - Mini-Kanban` | `Trash - Mini-Kanban` |

  首页（按登录态跳转）与 404 这类没有页面名的路由只显示 `Mini-Kanban`。
- **登录页卡片标题**：`Mini-Kanban - 任务看板系统`（英文 `Mini-Kanban - Task board system`）。
- **初始化向导与状态页**：标签页标题同步为「初始化配置 - Mini-Kanban」「运行状态 - Mini-Kanban」，
  页内主标题统一成 `Mini-Kanban`。

技术口径：页面组件是客户端组件、不能导出 `metadata`，所以页面名写在各自路由段的 `layout.tsx` 里
（`pageMetadata()`），路由与文案键的映射集中在 `web/lib/i18n/pageTitle.ts`，客户端跳转 / 切换语言时由
`DocumentTitle` 同步刷新 —— 静态导出产物在构建期只能写死默认语言，这一步保证切语言后标题跟着变。

### 升级

解压新包覆盖旧的即可，`config.yaml`（或 `setup` 向导）沿用原有配置，数据库无需迁移。

### 下载与校验

产物名仍带版本号，认准 `mini-kanban-v1.0.1-系统-架构`：Windows 为 `.zip`，Linux / macOS 为 `.tar.gz`，
均为 `CGO_ENABLED=0` 静态编译；`checksums.txt` 是全部归档的 SHA256，可用 `sha256sum -c` 校验。

## v1.0.1 · Unified branding and tab titles

A small patch release: no functional, API or database changes — only the product name and the browser tab titles.

### What changed

- **The product is now called `Mini-Kanban`** everywhere: the navbar brand, the tab titles and the login card all use
  the same name in both languages (it used to be 任务看板 / `Task Board`).
- **Tab titles are now `page name - Mini-Kanban`**, per route: `Sign in - Mini-Kanban`, `Projects - Mini-Kanban`,
  `Task board - Mini-Kanban`, `Users - Mini-Kanban`, `Departments - Mini-Kanban`, `Activity logs - Mini-Kanban`,
  `Trash - Mini-Kanban`. Routes without a page name (home, 404) show `Mini-Kanban` alone.
- **Login card title**: `Mini-Kanban - Task board system`.
- **Setup wizard and status page**: tab titles became `初始化配置 - Mini-Kanban` / `运行状态 - Mini-Kanban` with
  `Mini-Kanban` as the on-page heading.

Implementation note: pages are client components and cannot export `metadata`, so each route segment's `layout.tsx`
declares its page-name key via `pageMetadata()`; the route-to-key map lives in `web/lib/i18n/pageTitle.ts` and
`DocumentTitle` refreshes the title on client-side navigation and language switches (static-export builds can only bake
in the default language at build time).

### Upgrading

Unpack the new archive over the old one and keep your `config.yaml` — no database migration is needed.

### Download and verification

Archive names still carry the version: `mini-kanban-v1.0.1-<os>-<arch>` (`.zip` for Windows, `.tar.gz` otherwise), all
statically compiled with `CGO_ENABLED=0`. `checksums.txt` holds the SHA256 of every archive (`sha256sum -c` to verify).
